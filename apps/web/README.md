# Web application

Next.js App Router app for the campus student portal.

## Commands

From the **repository root**:

```bash
npm run install:web
cp apps/web/.env.example apps/web/.env
npm run db:migrate
npm run db:seed
npm run dev
```

Or from this directory: `npm install`, then `npm run dev`.

See the [root README](../../README.md) and [docs](../../docs/README.md).
