# Web application

Next.js App Router app for the campus student portal.

## Commands

From the **repository root**:

```bash
npm install
cp apps/web/.env.example apps/web/.env
npm run db:migrate
npm run db:seed
npm run dev
```

Or from this directory: `npm install`, then the same `db:*` and `dev` scripts.

See the [root README](../../README.md) and [docs](../../docs/README.md).
