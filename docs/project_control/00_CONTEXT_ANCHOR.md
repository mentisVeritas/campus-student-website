# CONTEXT ANCHOR

Если потеряли контекст, начинаем отсюда.

## 1) Цель проекта
- За 1 день сделать рабочий сайт.
- Приоритет: работающий flow, а не идеальная архитектура.

## 2) Что такое "рабочий сайт" в нашем проекте
- Пользователь может войти в систему.
- Пользователь может открыть ключевые страницы: профиль, расписание, оценки, зачетка.
- Базовые разделы Should доступны и не ломают Must.
- Проект проходит `npm run dev` и `npm run build`.

## 3) Приоритеты
- `Must` -> `Should` -> `Could`.
- Если не успеваем: урезаем `Could`, затем `Should`.
- `Must` не ломаем и не откладываем.

## 4) Стек
- `Next.js` (App Router), `TypeScript`, `Tailwind CSS`
- Дополнительно при необходимости: `shadcn/ui`, `Zustand`, `React Hook Form`, `Zod`

## 5) Definition of Done
- Проект запускается (`npm run dev`) без падений из `apps/web`.
- Ключевые страницы открываются без 404.
- Must-сценарии проходят end-to-end без блокирующих ошибок.
- В `docs/project_control/03_TASK_BOARD.md` задачи отмечены по факту (`DONE`).

## 6) Как действовать, если потеряли контекст
1. Открыть `docs/project_control/03_TASK_BOARD.md`.
2. Проверить блок `FIXED FUNCTION REGISTRY` (F01-F35), чтобы не потерять функции из таблицы.
3. Найти блок `CURRENT STATE`.
4. Продолжить с поля `Текущая задача`.

## 7) Важные пути
- Рабочий план: `docs/project_control/03_TASK_BOARD.md`
- Архив, который не трогаем: `docs/_do_not_touch_docs/`
